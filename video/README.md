## Register

Written as a colleague explaining something, not a product demo. First person.
Admits where the design cost capability, and where it was got wrong first.

## Production standards

**Terminal:** 100 columns, dark background, 16pt minimum, default Unicode
output.

**Never speed up terminal output.** Cut instead. Accelerated text is unreadable
and looks evasive.

**Keep genuine errors.** A system that never fails on camera looks staged. This
one has honest failure modes worth seeing.

**No music, no lower thirds, no logo.** The terminal is the content.

**Pauses are marked and load-bearing.** Two seconds after a command completes
before speaking. The viewer is reading.

## The three moments that carry the series

If time is short, these are the passages to get right:

1. **Segment 1, 2:15** — the Service Centre Team Manager scoring 1.000 from a
   two-sentence summary
2. **Segment 3, 5:00** — git moved out of the exclusion list, pytest kept in,
   same day, same conversation
3. **Segment 6, 2:00** — the diagnose run that inverted its own diagnosis

Each is a real event with a real consequence. They do more work than any
explanation of the corresponding feature.
